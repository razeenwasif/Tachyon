Concept · Tachyon Next

What Tachyon is for

The Tachyon Next concept from 8 Nov, merged in here and kept current. A terminal for ML, AI, systems and HPC work from a MacBook, built on Metal, Core Text and Core Animation. It draws only what changed, does nothing at all when idle, and adds features other terminals don't have. Each part is marked against the installed app and the measurements on your M2 Pro.

What other terminals don't do

Seven features, each built on something Tachyon already has (a parser fast enough to replay gigabytes, a per-row damage map) plus what macOS exposes: per-process energy and P-core accounting, Core Animation and display links. “Closest today” is as far as we know, from the public docs of Terminal.app, iTerm2, Ghostty, WezTerm, kitty, Alacritty and Warp. Ghostty is the closest relative on the Mac; these features and the measured efficiency are Tachyon's argument.

ML · HPC · Systems
Run receipts, with energy
Built

Every command gets a receipt on its prompt line: exit code, wall time, CPU time and its share on performance cores, energy, and peak memory footprint. On unified memory, the footprint decides whether the next batch fits.

✓ 3m52s · cpu 11m40s (P 88%) · 2.3 Wh · 9.4 GB

Command boundaries come from OSC 133. CPU is exact, from the shell's child accounting; the rest uses kqueue (EVFILT_PROC NOTE_FORK | NOTE_EXEC | NOTE_EXIT) with proc_pid_rusage and PROC_PIDTBSDINFO (e_tpgid) so sub-500 ms children and local tachyon server Mux v2 panes all get peak footprint, energy and P-core share with zero idle wake-ups. A long command that finishes while you're elsewhere posts a notification with its receipt. Works in zsh, bash and fish.

Closest today: exit status and sometimes duration. Energy and P-core share per command are new.

ML · AI
Metric lens
Built

Numbers in output that look like metrics (loss=, acc, it/s, tok/s, tqdm's 45%|) become a readout on the prompt line, with a sparkline of the loss. A tqdm bar drives a progress bar on the Dock icon. The output stream is read as lines, so tqdm's in-place redraws count; floods are only sampled.

❯ python train.py loss 0.398 ▇▆▅▄▃▂ · 48.2 it/s · 45% · running 3m

Closest today: TensorBoard or W&B, outside the terminal. Some terminals honour OSC 9;4, which tqdm doesn't send.

ML · Systems · HPC
Rerun diff
Built

Run a command again and lines that differ from the last run get a gutter mark; hover one to see the old line. Compare two learning rates or two benchmark runs without leaving the terminal. Matched by structure first, then a Myers diff on lines.

~ epoch 2 train 3.902 val 3.807 acc 12.4% was train 3.704 val 3.640 acc 15.6%

Closest today: copying both outputs into a diff tool by hand.

HPC · ML
Job tabs
Built

The MacBook submits; forge and atlas run. When output contains a job ID (a detached Nexus job, or Slurm's Submitted batch job N), Tachyon offers to open it as a tab that follows the log. Its name shows its state (nexus j-1a2b3c4d · running on forge), and when it ends its receipt and notification say how. Slurm jobs submitted over ssh are followed through the same ssh. Diagram below.

Closest today: nexus logs or squeue plus tail -f, by hand.

ML · HPC
Runs that outlive the window
Built

Built: tachyon server owns the shells, screens, keep-awake assertions (⌥⌘A), and full server-side Rewind logs (including alternate-screen frames & LZ4 cold segments) on This Mac, Mac mini (kagutsuchi), Windows (amaterasu) & Linux. Quitting, crashing, or updating leaves runs going, reopening puts windows, tabs, splits and Rewind history back, and ⌘[/⌘]/⌥-click provenance work across remote hosts too.

Closest today: tmux or WezTerm's mux server, plus caffeinate -i by hand — neither keeps Rewind history across restarts or remote hosts.

Systems · AI
Latency ledger
Built

Every keystroke is timed through its whole path and the delay split between the shell, ssh and the terminal. Each stage is also an os_signpost interval, so Instruments shows Tachyon's own frames.

key→pty 0.1 echo 1.4 parse 0.02 draw 0.4 on glass 2.2 ms

Closest today: Typometer, or filming the screen with a high-speed camera.

Native where macOS is native, cells everywhere else

The window, menus and shortcuts are Apple's own, so Tachyon behaves like every other Mac app. Inside the window, everything Tachyon adds sits on the same cell grid as the text.

Chrome
Apple's chrome, or none
Built

A real NSWindow with the standard menu bar, ⌘ shortcuts and Stage Manager, on Liquid Glass. You use edge-to-edge: no title bar, buttons on hover in the top-left corner, tabs along the bottom. A standard layout puts a title bar on the glass with the tabs in it (View > Show Title Bar). Full screen around the notch (⌥⌘F) puts the tabs left of the notch and a status line right of it.

Appearance
Follows the system
Built

Built: paired light and dark palettes that switch with Light and Dark Mode, the system accent colour for the cursor and selection with accent, an opaque window with Reduce Transparency, and with Increase Contrast, high-contrast themes derived from yours (every ANSI colour at 7:1) on solid glass.

Layout
The grid is the layout
Built

Command bars, receipts and the tab strip are drawn in cells, aligned to the text, and the window resizes in whole cells so there's never a sliver. A command is marked by a one-cell gutter bar, not a card, so copying gets exactly what the program wrote. Split panes will land on cell boundaries too.

Type
Fonts rendered the Mac way
Partly built

Glyphs are rasterised by Core Text at the display's backing scale with grayscale antialiasing, and fallback comes from CTFontCreateForString. The concept proposed SF Mono; you chose Cascadia Mono, with SF Mono as the fallback. Still to do: ligatures and emoji sequences through Core Text shaping.

Icon
One cursor, moving faster than it should
Built

Most terminal icons are a >_ prompt. Tachyon's is the block cursor on a dark squircle with a trail behind it. Below 32 pt the trail is dropped and the cursor grows. It ships as two Icon Composer layers so macOS can make the Clear and Tinted looks.

Known gaps

Rough edges in the installed app.

  • Emoji sequences
    Fixed

    Skin tones, ZWJ families and flags now draw as one glyph, shaped by Core Text. Cells keep the widths the shell counts, so a family emoji leaves blank cells after it.

  • Display latency
    Fixed

    Median keystroke to screen went from 33–35 ms to 23–25 ms, measured against the previous build under the same load. An idle window draws the echo at once; in a window, frames go to the compositor without waiting for vsync (render.low_latency); the link asks for 120 Hz and drops to 60 Hz while output streams. What's left is about two refreshes in the compositor.

  • Nerd Font branch icon
    Fixed

    The branch symbol spanned 35 px in a 28 px cell: Powerline glyphs fill their own font's line, which is taller than Cascadia Mono's. The Nerd Font fallback is now sized so its line is the cell's and placed on the cell's box; icons sit inside the cell and Powerline arrows fill it exactly.

  • Increase Contrast palette
    Built

    With Increase Contrast on, both themes switch to high-contrast versions derived from them: black or white background, every ANSI colour at 7:1 (4.5:1 for the dim suggestion slot), a solid selection, and the glass tinted solid. Follows the setting live; theme.contrast fixes it. Checked with theme.contrast = high; flipping the system setting is yours to try.

  • Receipts and right prompts
    Fixed

    A receipt now sits just left of a right prompt (conda's (base) in fish, zsh's RPROMPT), keeping two blank cells from the command; checked side by side with the previous build, where it was hidden.

Guide

Using Tachyon

Tachyon is a GPU terminal for your MacBook: Metal for drawing, Core Text for fonts, and a login zsh in every tab. The diagrams show how its parts work and a few everyday uses. This covers the installed app, as installed on 9 Nov at 09:57, and is updated after each build.

Getting started

  1. Open it

    Tachyon is in Applications. It opens one window running your login zsh, so your .zshrc, Starship and zoxide load as usual.

  2. Tabs and windows

    ⌘T opens a tab and ⌘N a window, each with its own shell. Closing the last window keeps Tachyon running; click its Dock icon for a new one.

  3. Find your commands

    Each command gets a bar in the left gutter. ⌘↑ and ⌘↓ jump between them, and a receipt appears when one finishes.

  4. Change it

    Settings live in ~/.config/Tachyon/tachyon.conf. Yours sets new windows to 173 × 51 cells, about 1228 × 727 points; everything else is the default, like Cascadia Mono at 12 pt.

The window

The grid runs all the way to the top edge, so you get every row of the screen. The window buttons stay hidden until you need them.

Edge-to-edge window
  1. 1Window buttonsMove the pointer into the top-left corner and close, minimise and zoom fade in. Clicks there still reach the cells when the buttons are hidden.
  2. 2Moving the windowDrag along the top edge, or hold ⌃⌘ and drag anywhere. Double-clicking the top edge does nothing, so it never fills the screen by accident.
  3. 3Command barsEach command's prompt and output get a bar in the gutter, coloured by how it ended.
  4. 4ReceiptsWhen a command ends, its receipt is written on the prompt line, or on the next row if the line is full.
Windows
  • New window with ⌘N; each runs its own shell.
  • Close with ⌘⇧W, or ⌘W on the last tab. Shells are hung up and reaped, so nothing is left running.
  • No windows left: Tachyon stays in the Dock; click it for a new window.
  • Tabs: ⌘T opens one; see Tabs below.
Look
  • Cascadia Mono at 12 pt, with SF Mono as the fallback and Nerd Fonts for prompt icons.
  • Box drawing and blocks are drawn as shapes, so lines join with no gaps.
  • Text size: ⌘+, ⌘−, ⌘0, per window.
  • The cursor blinks in Core Animation, so blinking costs no frames.
  • Liquid Glass sits behind the text: the default background lets your wallpaper through, softly blurred, while text and colours stay solid. The glass itself is tinted with the theme's background (window.glass_tint, 0.75), which keeps its refraction; window.glass = regular frosts it more, and window.backdrop = none turns it off.
  • Light Mode switches to a light theme and back with the system; theme.appearance fixes one.

Tabs

With two or more tabs, they appear along the bottom edge; with one, they go away and the grid gets the space back. On Liquid Glass the tabs float in a glass capsule, sized to the tabs, with the one in front on a softer pill. Without glass they're drawn in cells as a strip, as in the diagram below, with the tab in front sharing the terminal's background.

Names and dots
  • While a command runs, the tab shows its command line, like python train.py --epochs 3, or a title the program sets, like vim's.
  • At a prompt, it shows the folder: Tachyon, or ~ at home.
  • A dot appears when a command finishes in a tab you aren't looking at: green if it succeeded, red if it failed. It clears when you show the tab.
Moving between tabs
  • ⌘1 to ⌘8 show that tab; ⌘9 the last one.
  • ⌘⇧[ and ⌘⇧], or ⌃⇥ and ⌃⇧⇥, step through them.
  • Click a tab to show it, middle-click to close it.
  • ⌘W closes the tab in front (or, in a split tab, the pane with focus); the tab to its right comes forward. Typing exit closes it too.
  • Rewind: ⌘[ shows the screen a moment earlier, even what htop or vim drew before they exited; ⌘[ again goes further back, ⌘] forward, and esc or any key returns to live. A glass badge at the top says how long ago, with a slider to drag through every frame kept; the wheel steps them too. ⌥-click a cell to see which output wrote it and when. Older output is kept on disk, compressed, until the tab closes.
  • Job tabs: after nexus gpu … --detach or sbatch, the prompt line offers ⌘J follows j-1a2b3c4d. ⌘J, or ⌘-click on the id, opens a tab that follows the job's log, named after its state, like nexus j-1a2b3c4d · running on forge.

Split panes

A tab can hold several shells side by side or stacked. Each pane is a full session of its own, with its own scrollback, Rewind, receipts and notifications. The tab is named after the pane with focus, and the other panes are veiled slightly so you can see where your keys go.

Splitting and closing
  • ⌘D splits the pane with focus side by side; ⌘⇧D one above the other. The new shell starts in the same folder, unless that pane is in an ssh session.
  • ⌘W or exit closes a pane; the rest of its split takes the space and the focus. The last pane closes the tab.
  • ⌘⇧↩ zooms the pane with focus to fill the tab; again puts it back. The others keep running.
Moving and resizing
  • ⌘⌥← ⌘⌥→ ⌘⌥↑ ⌘⌥↓ move focus to the pane on that side, or click one.
  • Drag a divider to resize the panes beside it; the pointer changes over it. Sizes snap to whole cells.
  • The wheel scrolls the pane under the pointer without taking focus, so you can read back through a log while typing elsewhere.

Quitting and coming back

Your shells don't live in the Tachyon window. They live in a small background process, the session host, and the window is a view onto them. So quitting Tachyon, a crash, or installing an update leaves them running: a training run keeps going and an ssh session stays connected. Open Tachyon again and everything is where you left it.

What comes back
  • Windows, tabs and splits, in the same places, with the same tab in front and the same pane focused.
  • Each screen: scrollback, colours, and a full-screen program (htop, vim) exactly as it is now, since the host kept watching while the window was closed.
  • Command marks and their exit codes, so ⌘↑ and the gutter bars still work. Restored commands have no times in their receipts, and Rewind starts again from the restored screen.
Ending shells
  • ⌘Q quits and keeps the shells. ⌥⌘Q (Quit and End Shells) ends them too.
  • Closing a tab, pane or window ends its shells, as always.
  • The host leaves by itself 20 seconds after it has nothing to run. Set shell.persist = false to have shells end with the app.
Keeping the Mac awake
  • ⌥⌘A keeps the Mac awake while the pane's command runs: the one running now, or at a prompt the next one you start. It lasts that one command.
  • The receipt reads ☕ awake · running 2h 14m while it holds; a prompt says ☕ the next command keeps the Mac awake until then.
  • The host holds it, so quitting Tachyon doesn't let the Mac sleep mid-run. It stops idle sleep only, like caffeinate -i: the display still sleeps, and so does a closed MacBook on battery. pmset -g assertions shows it by command.

Text and the mouse

Selecting
  • Drag to select by character. Starting on the right half of a letter leaves that letter out, as in other Mac text views.
  • Double-click takes a word. A path or URL counts as one word.
  • Triple-click takes the whole line, across wrapped rows.
  • ⌘C copies without trailing blanks; ⌘A selects everything, scrollback too.
Programs that use the mouse
  • htop, vim, tmux and similar get clicks, drags and the wheel when they ask for them.
  • Hold ⇧ to select text anyway while a program has the mouse.
  • ⌘-click a path to see the file in Quick Look, or a URL to open it. Paths are found from the tab's folder; ls of another folder prints bare names, which won't resolve.
  • The wheel scrolls back through history when no program has the mouse.
Keys
  • Option as Meta is off by default, so ⌥ types accents. Set macos.option_as_meta to left, right or true for Meta.
  • Secure Keyboard Entry turns on by itself while sudo, ssh or another program asks for a password, so other apps can't read those keys, and the prompt line says so.
  • Dead keys and input methods work: ⌥E then E gives é, and Pinyin or Japanese show what you're composing, underlined.

Commands and receipts

Tachyon loads its own integration into zsh, bash and fish on top of your config, so it knows where each prompt, command and its output start and end. None of your startup files change.

Reading a receipt

✓ 3m52s · cpu 11m40s (P 88%) · 2.3 Wh · 9.4 GB

  • ✓ or ✗ code: how it ended.
  • Wall time, then CPU time across all its processes, exact.
  • P share: how much of that CPU ran on performance cores.
  • Energy in J or Wh, from the kernel's per-process energy counter.
  • Peak footprint: the most memory it held at once, the number that decides whether the next batch fits in 16 GB.
Moving around
  • Suggestions: as you type at a prompt, the rest of a command you've run before shows in grey, like cargo test --release. →, End or ⌃F types it in; ⌥→ one word. They come from your shell's history and every command run in Tachyon, newest first and the same folder first. A leading space keeps a command out; shell.suggestions = false turns them off.
  • Rerun diff: run a command again, even with different numbers like a new learning rate, and the lines that differ from the last run get an amber gutter mark. The prompt line says how many; hover a mark for the old line.
  • Metric lens: while a training run or server prints metrics, its prompt line shows them, like loss 0.398 ▇▆▅▄▃▂ · 48.2 it/s · 45%, with a sparkline of the loss. A tqdm bar also shows on the Dock icon as a progress bar.
  • ⌘↑ jumps to the previous command's prompt, ⌘↓ to the next.
  • Long runs: a command that took 10 s or more and finished while you were in another app or window posts a notification with its receipt. Click it to go to its tab. Change the time with notify.after, or set it to 0 to turn it off.
  • Turn it off with shell.integration = false.
  • bash and fish get the same: set shell.program to either and Tachyon loads the integration itself, without touching your startup files. bash works from macOS's 3.2 on, alongside a starship prompt.
  • Over ssh, copy the script to the other machine and load it from your startup file, for bash: [[ $LC_TERMINAL == Tachyon ]] && source ~/.tachyon-integration.bash. ssh passes LC_TERMINAL, so it turns on only in Tachyon. The README has zsh and fish.

When something's off

Things that look like bugs
  • Tachyon quits when the last window closes: that's Vorssaint, which quits apps with no windows. Tachyon itself stays open; add it to Vorssaint's exceptions.
  • A new window opens off to the side: Stage Manager parks windows opened in the background. Click Tachyon in the Dock first.
Looking closer
  • The log is ~/Library/Logs/Tachyon/tachyon.log, which Console.app also shows.
  • Record a session's raw output by starting Tachyon with TACHYON_DUMP=/path/to/file, to replay a rendering problem later.
  • Reinstall from the repo with scripts/bundle-macos.sh --install.
